# This session

You are already authenticated. A credential was minted for this session alone and is
attached to your requests automatically. You will never see its value and do not need it.

**Do not run `nyxid login`.** There is nobody to log in as. The same goes for
`nyxid whoami`, `nyxid status` and `nyxid service list`: they ask about a user account,
this session is not one, and they will fail however many times they are tried.

Reach a service with `nyxid proxy request <slug> <path>`.

A call to anything else is refused for the life of this session. It is not worth
