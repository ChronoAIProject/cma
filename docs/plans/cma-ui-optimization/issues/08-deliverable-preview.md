# 08：点击成果卡片在右侧预览

**What to build:** 用户点选回答中的成果，即可在会话旁查看对应文件或文档，并能返回原来的阅读与输入位置。

**Blocked by:** 07（经过验证的回答资源身份、授权与版本）。

**Status:** done

**优先级:** P1

## Acceptance criteria

- [x] 选中成果卡片打开对应右侧预览，卡片高亮与资源身份一致；沿用已有文件和文档渲染器，不创建独立会话。
- [x] 支持既有安全文本/Markdown/图片预览；其他格式如 PDF 仅在已有隔离预览能力可用时显示，否则保留下载与清楚的“不支持预览”说明。
- [x] 加载、错误、过大、已删除、版本已变更和权限失效有独立状态；晚到的 A 预览不能覆盖已选 B。
- [x] 不执行文件里的脚本，不把原始 HTML、SVG 或不可信链接当同源交互页面；超限内容按原预览上限处理。
- [x] 切换预览/详情/文件面板及关闭面板不会重挂载消息流或 composer；草稿、附件、滚动位置和正在保存的文件编辑保持安全。
- [x] 移动端使用可返回的面板/覆盖层，关闭后恢复到原卡片焦点；键盘可以打开、关闭与下载。
- [x] 非 owner 按资源权限独立读取；只读预览不显示保存入口，权限撤销后清除受限内容。

## Testing boundaries（2026-11-03 已确认）

- **U/A：** 卡片选择→真实授权预览/下载→关闭返回；验证资源切换竞态和权限。fixture 无法证明任意文件的内容安全。
- **真实浏览器：** 触屏/键盘焦点、容器宽度、危险样本隔离和会话保持；不以 CSS class 断言代替可见交互。
- **首个 red → green：** 输入框有未发送文字时选中成果、切换第二个成果并关闭预览，文字与原会话位置均保留。
