# 18：按操作记录回放并返回实时状态

**What to build:** 用户通过时间线查看一轮任务的历史操作与结果，然后返回当前实时工作；查看历史不会重执行任何动作。

**Blocked by:** 14（电脑面板及已授权的操作数据范围）。

**Status:** done — `codex/cma-ui-18`；已合并集成 `7cd701d0f`，U/A/R 证据见 [18-EVIDENCE](../18-EVIDENCE.md)，路径清单见 [18-FILE-SCOPE](../18-FILE-SCOPE.md)。

**优先级:** P3

## Acceptance criteria

- [x] 使用持久 Agent 事件、turn 身份与稳定游标建立回放索引，公开接口有边界和分页；不按工具数组下标或前端观察时间建立历史身份。
- [x] 面板提供可键盘操作的回放进度/上一步/下一步，以及“返回实时”；明确标记“操作记录回放”，未录屏时不显示伪历史浏览器画面。
- [x] 选中位置显示该步已记录的命令、输出、状态、时间和可用计划快照；无历史快照的字段标记未记录，不用最新状态填充过去。
- [x] 完成页可进入对应 turn 的过程；06 已接入时“查看计划和回放”定位到同一轮。没有计划也能独立回放操作。
- [x] 回放期间实时事件继续安全接收但不把用户拖回末尾，返回 Live 后衔接最新游标；重连重放去重，分页边界、缺口与保留期到期可见。
- [x] Agent/账号/权限切换取消旧请求并清空越权内容；旧 Agent 的回放结果不串入当前页。
- [x] 回放不会发送命令、触发审批/反馈/建议发送、恢复已结束任务或获得控制权；历史模式下真实控制动作明确不可用。
- [x] 刷新后的回放位置按授权重读，日志截断或内容不可用有说明；文件内容未保存快照时不会把当前文件展示成历史成果。

## Testing boundaries（2026-11-03 已确认）

- **A/U：** 公开历史分页→游标定位→面板→返回实时；检验乱序/重连/缺口与历史阅读期间新事件。不能证明屏幕录像存在。
- **R：** 隔离 Agent 执行几个无害操作，刷新后经公开历史回放已知输出，核对没有额外执行；不要求浏览器帧能力。
- **首个 red → green：** 用户停在操作 2 时新操作 4 到达，仍显示操作 2；点返回实时看到操作 4，执行记录没有新增命令。
