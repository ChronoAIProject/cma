# 14：常驻 Agent 电脑面板展示文件与操作输出

**What to build:** 用户在对话旁持续查看 Agent 的文件和真实命令活动，切换面板时不丢失会话或未保存内容。

**Blocked by:** None（复用现有文件侧栏和工具事件）。

**Status:** ready-for-agent

**优先级:** P3

## Acceptance criteria

- [ ] 支持的宽屏布局默认显示右侧“Agent 的电脑”，用户可收起；窄屏用明确入口与可返回面板，保留对话阅读宽度、composer 和键盘焦点。
- [ ] 文件 tab 继续使用当前授权文件树、读取、下载及 owner 编辑能力；切走/关闭时尊重未保存文件草稿，不能以重挂载丢弃修改。
- [ ] 终端活动 tab 只显示该 Agent/turn 已记录的命令及输出，按顺序提供运行、失败、取消、截断和未报告状态；不支持命令输入，不请求已退役的 PTY。
- [ ] 环境能力及拒绝原因由公开的可信状态提供，定义 browser/files/operation-output/replay/control 的支持状态与作用范围；加载中、unsupported、未启用、权限不足和暂时故障可区分。
- [ ] 没有浏览器能力时显示说明，不放假浏览器图和 Live 标记；15 接入后使用同一 panel scope。shared view 只提供获授权的数据和动作。
- [ ] 面板、历史和消息流共享当前事件观察结果，避免为每个 tab 再建立重复整段订阅；隐藏页面停止无必要轮询，重新打开按游标恢复。
- [ ] Agent/账号/权限改变立即隔离旧数据与晚到回调；不会展示同 Sandbox 其他 Agent 的文件、进程或输出。
- [ ] 详情、文件预览与电脑面板保持单一可理解的选中状态；其更新不重挂载会话、不清空文本/附件/滚动位置。

## Testing boundaries（2026-11-03 已确认）

- **U/A：** 面板切换→真实文件读取/活动流→权限变化，验证文件修改保护和 Agent 隔离；输出必须来自可回读的实际事件。fixture 无法证明 runtime 报告完整性。
- **R：** 固定 runtime 执行已知无害命令，页面读到对应输出；明确缺失时展示未报告。该证据只证明日志观察，不证明 PTY 能力。
- **真实浏览器：** 默认宽屏、收起恢复、手机返回、焦点和 composer DOM 连续性。
- **首个 red → green：** 有未发送草稿时在文件与终端活动间切换，看到对应 turn 的已知输出，原草稿与阅读位置不变。
