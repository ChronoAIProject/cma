# CMA SDKs

CMA's integration documentation lives with the independently published SDKs:

- [TypeScript SDK guide](../sdk/typescript/docs/README.md)
- [Rust SDK guide](../sdk/rust/docs/README.md)

Those files ship with their packages and are the designated source for the CMA
Developer surface. The public wire contracts remain in the interface documents:
[REST](API_REST.md), [AG-UI](API_AGUI.md), [PTY](API_PTY.md), [MCP](API_MCP.md),
and [A2A](API_A2A.md).
